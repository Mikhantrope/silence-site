# SILENCE v32 — отчёт об оптимизации

## Изменения без переработки дизайна

База: полный архив v31 с изображением BIART. Код и стили объединены по назначению страницы, старые модули исключены из подключения. Размеры изображений подбираются через srcset; оригиналы остаются в просмотрщике.

## Изображение дома

Сравнение одного размера: 1040×1040 — 180 518 байт исходного WebP → 79 353 байта AVIF (−56,0%). 720×720 — 71 832 → 42 910 байт (−40,3%). Для браузеров без AVIF остаётся WebP. По ширине и плотности экрана браузер выбирает подходящую версию, а не обязан всегда загружать наименьшую.

Подготовлены 162 WebP-варианта для 76 исходных изображений, плюс шесть вариантов дома и маленькая копия логотипа. Логика viewer использует исходные фотографии/схемы, поэтому мелкий текст не заменяется сжатым превью.

## Отложенная загрузка

Главная картинка обнаруживается в HTML, имеет fetchpriority=high и адаптивный preload. Изображения карточек не конкурируют с первым экраном: загрузчик использует IntersectionObserver с запасом 350px. Статические статьи содержат текст и обычные HTML-ссылки независимо от выполнения JS.

## Шрифт и кеш

Google Fonts подключён неблокирующим CSS media=print, переключение на all выполняет маленький разрешённый CSP-хешем загрузчик. При недоступности сервиса остаётся системный fallback. Файлов шрифтов в пакете нет. Общие JS/CSS названы по содержимому и используются повторно между страницами; стандартные HTTP-заголовки GitHub Pages не менялись.

## Проверки и пределы достоверности

Пройдены 48 проверок страницы/ширины (16×3), дополнительные функциональные сценарии и статическая проверка локальных ресурсов. Подробные результаты находятся в QA-PERFORMANCE-v32.json.

Стандартная браузерная навигация здесь блокируется политикой среды, поэтому использован офлайн DOM-стенд: JS/CSS встроены, сетевые запросы не измерялись, изображения поданы тестовыми уменьшенными копиями. Этот стенд подтверждает работоспособность интерфейса, но НЕ позволяет заявить фактическое ускорение в секундах, Lighthouse score, LCP, INP или TTFB. Safari и физические устройства не проверялись.

## Эксплуатация

Для публикации достаточно готовых файлов. Полный пакет включает оригиналы и исходники, но браузер не скачивает весь пакет. Увеличение ZIP из-за responsive-копий не означает увеличение нагрузки при открытии страницы. После публикации измерьте именно адрес GitHub Pages в PageSpeed/DevTools; результаты из других сетей и устройств могут отличаться.
