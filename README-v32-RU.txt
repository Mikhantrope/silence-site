SILENCE v32 — полный сайт, оптимизация загрузки

УСТАНОВКА
1. Распакуйте архив. index.html находится в корне рядом с assets, build, css и js.
2. Скопируйте весь комплект в папку silence-site с заменой. Папку .git не удаляйте.
3. В GitHub Desktop: Commit to main → Push origin.
4. Проверьте завершение публикации GitHub Pages в Actions.

ОБЯЗАТЕЛЬНО загрузите новые папки build и assets/fast. HTML теперь подключает
готовые сборки из build. Замена одного index.html или только файлов js недостаточна.
На хостинге НЕ нужен Node.js или npm. Сайт уже собран и работает как статические файлы.
Старые файлы вне архива не мешают, поскольку обновлённые страницы на них не ссылаются.

ЧТО ИЗМЕНЕНО
— Сохранены вёрстка, комнаты и подписи, материалы, схемы, BIART, статьи, формы и языки.
— Один объединённый CSS для основных страниц, отдельный лёгкий CSS для статей.
— Общий JS кешируется между страницами, отдельные небольшие скрипты по назначению.
— Удалены из загрузки неиспользуемые старые модули. Код отформатирован компактно.
— Консультация не загружает каталог, схемы, массивы товаров и нормативов.
— Основной текст уже присутствует в HTML, не нужно ждать JS, чтобы его увидеть.
— Внешний шрифт не блокирует показ страницы. Пока он недоступен, работает системный.
— Responsive WebP-превью и отдельные размеры картинки дома, AVIF с WebP-резервом.
— Дом загружается приоритетно; изображения ниже — при приближении к экрану.
— Оригиналы сохранены для увеличения, технических страниц и просмотрщика.
— Имена JS/CSS с отпечатком содержимого защищают от смешивания старых сборок.

ПРОВЕРКА
16 основных HTML-страниц × 3 ширины (320, 768, 1440) в офлайн-стенде Chromium.
Дополнительно выбор комнат, подписи, мобильное меню, карусель и её конец,
переключение категорий, просмотрщик и зум, исходная страница журнала,
6 вкладок объектов, языки/темы, проверка пустой формы и поиск статей.
985 локальных HTML-ссылок/ресурсов, 20 блоков JSON-LD, 16 CSP-хешей загрузчика,
162 responsive-превью проверены; ошибки не обнаружены в этих проверках.

ОГРАНИЧЕНИЯ
Это не замер реальной скорости сети и не результат PageSpeed Insights.
Навигация браузера к публичным и локальным адресам заблокирована средой проверки.
DOM/вёрстка проверялись с локально встроенными ресурсами и уменьшенными тестовыми
превью. Загрузка внешнего шрифта, TTFB, LCP/INP по реальной сети, Safari и физические
телефоны не проверены. После публикации нужен отдельный замер опубликованного сайта.
GitHub Pages и качество сети посетителя остаются внешними факторами.
Заголовки CDN в этом архиве не изменяются; .htaccess или фиктивное кеширование не добавлены.

РАЗМЕР АРХИВА
Полный архив содержит оригиналы и новые облегчённые версии одновременно. Браузер
не скачивает весь ZIP: на каждой странице загружается только нужная версия изображения.
Поэтому размер полного архива не равен весу одного открытия страницы.

ДЛЯ ДАЛЬНЕЙШИХ ПРАВОК
Исходники css и js сохранены. После изменения исходного кода выполните:
  npm install
  npm run build
Это пересоберёт build с новыми хешами и обновит ссылки в HTML. Не загружайте node_modules.
При изменении текста обновляйте и статический RU-текст в HTML: сборщик сохраняет его,
но не генерирует заново. Изображения в assets/fast уже подготовлены; менять размер
оригиналов без обновления responsive-копий и ASSET-SIZES-v32.json не следует.
В архиве нет файлов шрифтов; семейство Commissioner подключается из Google Fonts.

Детали и цифры: PERFORMANCE-v32.md и QA-PERFORMANCE-v32.json.
Предыдущая версия v31 может быть возвращена полным комплектом.
