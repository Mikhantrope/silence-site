SILENCE v29 — полный сайт

В архиве весь сайт. Старые архивы для сборки не нужны.

Установка:
1. Распакуйте ZIP. index.html находится сразу в корне распакованного содержимого.
2. Скопируйте содержимое в существующую локальную папку silence-site с заменой.
3. Не удаляйте .git.
4. GitHub Desktop: Commit to main, затем Push origin.

При ручной замене обновите три файла:
index.html → корень сайта
css/redesign.css → папка css
js/ui.section.js → папка js

В index.html изменены ссылки на CSS и JS на ?v=29. Изображения не изменялись.

Что посмотреть:
Нажмите на комнату: появится название шума и кнопка «Показать решения».
Выбранная комната слегка подсвечена, остальные три приглушены, центральная квартира не затемняется.
Переключайте комнаты без прыжков страницы; переход вниз — по кнопке подписи.

Полный перечень проверок и ограничений: QA-v29.json.
