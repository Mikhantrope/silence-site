# SILENCE v42 — полное отключение звука при выборе SILENCE

Основа: `silence-v41-room-sounds-full-site.zip`.

## Изменение
- «Стена + SILENCE» переводит громкость игрового аудио точно в 0. Существующий плавный переход занимает 0,22 секунды, после него звук полностью выключен.
- Надпись «90% поглощения», остаточная визуальная волна 10%, геометрия и рисунок «Отражённого фронта» не изменены.
- «Показать без SILENCE» возвращает звук; «Вернуть SILENCE» снова выключает его.
- Выбор другой стены возвращает прежнюю логику её громкости.
- Выбор комнаты, изменение общего регулятора и включение/возобновление аудио не обходят mute, пока выбран SILENCE.
- Аудиозапись продолжает воспроизводиться без звука, поэтому сравнение не перезапускает её.
- Строка состояния теперь сообщает «SILENCE включён — звук выключен.», а не «Звучит» в режиме mute.

Это изменение аудио-механики игры, а не новое утверждение об эффективности материала. Тексты страницы, фотографии, галерея, аудиофайлы и остальные разделы сохранены.

## Файлы
- `index.html`: ссылка на `build/home-game.v42.js` вместо v41, номер сборки.
- `build/home-game.v42.js`: новое подключение игры.
- `js/home-game.js`: синхронизированная читаемая копия.
- `package.json`: номер версии 42.0.0.

Проигрыватель `build/room-audio.v41.js` и сами MP3 остаются прежними. Старые файлы build сохранены для совместимости.

## Установка
Распаковать полный архив и скопировать содержимое в репозиторий с заменой, не удаляя `.git`. Затем Commit to main → Push origin. В обновлении v41 → v42 обязательно заменить `index.html` и загрузить `build/home-game.v42.js`.

Результаты фактических проверок этой сборки: `QA-v42.json`. Публикация в GitHub не выполнялась.
