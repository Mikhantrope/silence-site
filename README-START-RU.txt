SILENCE v26 — ПОЛНЫЙ САЙТ
=========================
Это полная сборка, а не обновление из нескольких файлов.
В корне находятся index.html и остальные страницы; рядом — assets, css, js, data и tools.

ПУБЛИКАЦИЯ В GITHUB
1. Распакуйте ZIP.
2. Откройте папку, в которой лежит index.html.
3. Скопируйте всё её содержимое в локальный репозиторий silence-site с заменой файлов.
   Не копируйте внешнюю папку архива внутрь репозитория. Папку .git не удаляйте.
4. GitHub Desktop: Commit to main, затем Push origin.
5. При уже настроенном Pages оставьте прежние main и /(root).
   Проверяйте завершение публикации во вкладке Actions, а не только обновлением браузера.

ЛОКАЛЬНЫЙ ПРОСМОТР
В папке сайта выполните: python -m http.server 8000
Откройте http://localhost:8000/
Здесь публикуется только статическая часть; заявки такой сервер не принимает.
server.py и start.bat/start.sh сохранены как существующие вспомогательные файлы.

ЧТО ВКЛЮЧЕНО
- Главная, каталог, системы, профессионалам, галерея, контакты.
- Изображения разреза дома, девять постеров карусели, шесть изображений типов объектов.
- Просмотр постеров поверх страницы, масштабирование, закрытие и возврат фокуса.
- Последние мобильные исправления v26, responsive.css и обновлённые скрипты.
- Автоперелистывание карусели по умолчанию выключено.
- Форма с именем и телефоном; при ошибке отправки — явный переход в WhatsApp.

ОГРАНИЧЕНИЯ
- Доставка заявок через /api/lead требует отдельного настроенного сервера.
  GitHub Pages не исполняет Python. Наличие формы не означает доставку заявки.
- Файлы с характеристиками и сгенерированные постеры не были технически переаттестованы.
  Постер AcousticWood Line / Art содержит ранее отмеченные расхождения с журналом.
  До рекламы характеристики нужно согласовать с изготовителем.
- SEO-шаблон __SITE_URL__ сохранён как в исходной версии: этот архив не является
  отдельным завершённым SEO-релизом.
- Шрифт Commissioner подключён через Google Fonts. При недоступной сети используется
  системный запасной шрифт. Изображения и код находятся внутри архива.
- Эмуляция мобильных размеров в Chromium не заменяет проверку на реальном iPhone/Android.

Справка GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

ПРОВЕРКА ЭТОЙ СБОРКИ
Проверены локальные зависимости HTML/CSS, прямые пути к изображениям в JS,
синтаксис всех JS-файлов и целостность ZIP. Повторный полный браузерный прогон
