# SILENCE v49 — SEO Stage 3

Этап: on-page SEO, заголовки, сниппеты, семантика и мультиязычные метаданные.

## Что изменено
- Переписаны Title и Description основных коммерческих страниц под реальные поисковые задачи, без переспама.
- Обновлены Open Graph и Twitter title/description на основных страницах.
- Для gallery.html добавлен полный набор Open Graph / Twitter metadata.
- H1 основных страниц сделаны конкретнее:
  - главная — звукоизоляция + акустические системы;
  - каталог — звукоизоляционные материалы + акустические панели;
  - системы — стены / потолок / пол / перегородки;
  - объекты — звукоизоляция + акустические решения;
  - профессионалам — проектировщики + дизайнеры;
  - контакты — расчёт + консультация по звукоизоляции;
  - галерея — звукоизоляционные + акустические решения.
- Обновлены лиды основных страниц, чтобы поисковику и посетителю было понятнее назначение страницы.
- Русские статические версии сохранены как индексируемый fallback.
- При переключении RU/KZ/EN теперь меняются browser title и meta description для основных динамических страниц.
- На странице каталога карточки товаров переведены с H3 на H2, при этом на главной карточки остаются H3.
- На полной странице объектов карточки и выделенные объекты используют H2, на тизере главной остаются H3.
- Галерейный hero получил RU/KZ/EN переводы для заголовка, лида и блока видео.

## Что намеренно НЕ делалось на этом этапе
- Не создавались отдельные /ru/, /kk/, /en/ URL и hreflang. Это отдельный этап и требует изменения архитектуры.
- Не добавлялись Google Search Console / Яндекс.Вебмастер / Метрика / GA4.
- Не добавлялась Schema.org разметка — её лучше делать отдельным контролируемым этапом.
- Не создавались новые SEO-посадочные страницы, чтобы не плодить слабый контент.
- DNS, HTTPS и домен не менялись.
