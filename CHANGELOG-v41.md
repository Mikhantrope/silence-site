# SILENCE v41 — записи для четырёх комнат

Основа: полный архив `silence-v40-gallery-final-site.zip`.

## Что изменено

- На главной вместо синтетических звуков используются пять аудиофайлов, присланных пользователем: один для верхней комнаты, два сведены для левой, по одному для правой и нижней.
- Слева: постоянный работающий пылесос и четыре отдельные серии лая. Пауза между сериями — несколько секунд. Уровень фона слегка снижается на время лая и возвращается обратно. Сам лай не заменён и не сгенерирован.
- Снизу теперь указано «Концерт», а не «Кино / басы».
- Добавлены регулятор громкости (по умолчанию 35%), индикация загрузки и понятное сообщение при ошибке.
- Аудио загружается только по нажатию «Включить звук». При выборе другой комнаты во включённом режиме загружается только её запись. Уже загруженные записи переиспользуются.
- Смена стены и «до / после» не перезапускают запись. Пауза и возвращение к источнику сохраняют позицию.
- Переход в другую вкладку / уход со страницы ставит звук на паузу. Возобновление — только новым нажатием.
- Все четыре записи сохранены в MP3, 44,1 кГц, стерео, 160 кбит/с. WAV-исходники не добавлялись в публичную папку, чтобы не увеличивать загрузку сайта.
- Анимация «Отражённый фронт», геометрия, коэффициенты игры и изображения не изменены. Галерея и остальные страницы не изменены.

Уровни прослушивания выровнены, оставлен запас по пиковому уровню. Отдельный фильтр «соседняя комната» в записи не добавлялся: приглушение продолжает выполнять игра.

## Установка

Распаковать полный архив. Скопировать его содержимое в папку существующего репозитория с заменой файлов, не удаляя `.git`. В GitHub Desktop: Commit to main, затем Push origin.

Важно загрузить `index.html`, все новые файлы `build/*v41*` и папку `assets/audio/`. Переименовывать MP3 не нужно.

Для проверки на компьютере запустить `start.bat` (Windows) либо `start.sh` (macOS/Linux): требуется установленный Python. Затем открыть указанный локальный адрес. В режиме `file://` загрузка аудио через Fetch может блокироваться браузером; двойной клик по HTML не является способом проверки этой сборки. На GitHub Pages аудио работает через обычные относительные HTTPS-пути.

Оригиналы аудио остаются в переписке. Авторство / лицензии записей пользователем не предоставлены; в этой сборке не заявлено, что записи свободны от авторских прав.

## Разработка

`build/room-audio.v41.js` — проигрыватель; `build/home-game.v41.js` — подключение к игре. Читаемые копии лежат в `js/room-audio.js` и `js/home-game.js`. Новый стиль регулятора — `build/room-audio.v41.css`, копия в `css/room-audio.css`.

После изменения копий в `js/` синхронизировать соответствующие файлы `build/`; старый `npm run build` не собирает эти отдельные модули. Не менять имена без обновления ссылок в HTML.

Технические источники для реализации:
- https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/loop
- https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/setTargetAtTime
- https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/suspend

Результаты проверок: `QA-v41.json`. Проверки браузера выполнены в Chromium на локально подставленных ресурсах (offline harness); реальные телефоны, Safari и опубликованный сайт не проверялись. Ничего в GitHub не публиковалось.
