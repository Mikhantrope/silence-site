УСТАНОВКА ЧЕРЕЗ GITHUB DESKTOP
1. Сохраните предыдущую версию отдельно или убедитесь, что она закоммичена.
2. Распакуйте архив. Скопируйте всё его содержимое в локальную папку silence-site с заменой файлов.
3. index.html должен быть непосредственно в корне репозитория, без дополнительной вложенной папки.
4. Папку .git не удаляйте.
5. GitHub Desktop → Commit to main → Push origin.
6. Проверьте завершение публикации GitHub Pages и откройте сайт.

ПРОСМОТР ЛОКАЛЬНО
В папке сайта: python -m http.server 8000
Откройте http://localhost:8000/ . Python нужен только для локального просмотра, на GitHub Pages не запускается.

BIART: ЧТО ПОДТВЕРЖДЕНО
Название, образовательный профиль и адрес: официальный сайт https://biart.kz/ru/ (проверено 17.09.2026).
Сведения о применении решений SILENCE в музыкальных кабинетах: информация пользователя / компании SILENCE.
Не заявлены подтверждённые измерения, сроки, конкретный состав работ, количество кабинетов или площади обработки.
Изображение музыкального пространства — иллюстрация, не фотография BIART и не фото выполненных работ. Это явно подписано и в карточке, и на странице объекта.

КОНТАКТЫ И АНАЛИТИКА
Форма запрашивает имя и телефон и переводит в WhatsApp с подготовленным сообщением; посетитель отправляет его самостоятельно. Серверной доставки заявок нет.
Тема обращения не добавляется в сообщение.
Идентификаторы аналитики не выдуманы и не подключены; это по-прежнему отдельная настройка.

Статьи опубликованы только на русском; фиктивных hreflang/непереведённых языковых URL не добавлено.
Частотность запросов и позиции в поиске не измерялись. Ранжирование и сроки индексации не гарантируются.

ПРОВЕРКИ
QA-v30.json содержит статические проверки и результаты офлайн-стенда Chromium.
16 содержательных страниц проверены на ширинах 320, 390, 768, 1024, 1180 и 1440: 96 сочетаний.
47 функциональных проверок выполнены, включая поиск/фильтры, меню, комнаты, карточки, языки и доступность текста статей без JavaScript.
Прямые браузерные переходы в данном окружении заблокированы. Поэтому использован офлайн DOM/resource-стенд: ресурсы сайта подставлялись из локальной сборки, внешние шрифты отключены; CSP снят только в стенде, хранилище/история имитировались. В самих файлах CSP сохранён.
Проверки реального хостинга, внешних источников, отправки сообщений, Safari и физических смартфонов не выполнялись.
Архив проверен на целостность и наличие локально подключаемых файлов.
