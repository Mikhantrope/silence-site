Node.js/npm на GitHub Pages не нужны. Все изображения и build включены.

1. На главной, в «Объектах» и на странице BIART подпись под фото — «BIART, Астана».

ОПТИМИЗАЦИЯ СОХРАНЕНА
Оригинальные файлы изображений v32 не менялись. Картинка дома, анимация, меню,
форма, статьи и карусель сохранены. Новые зависимости/внешние виджеты не добавлялись.
Главная и «Объекты»: 2 скрипта + 1 локальный CSS, как в v32.
Новая страница: лёгкий редакционный комплект (1 JS + 1 CSS).
Исходники и готовые build-файлы обновлены вместе; русский HTML содержит новую карточку
и новую подпись даже без JavaScript. Новые хеши сборки автоматически записаны во все HTML.

УСТАНОВКА
Распакуйте и скопируйте всё содержимое (index.html, assets, build, css, js, projects и т.д.)
в локальную silence-site с заменой. Не создавайте вложенную папку сайта, не удаляйте .git.
GitHub Desktop → Commit to main → Push origin. Дождитесь успешной публикации Pages.
В GitHub из чата ничего не публиковалось.

МАЛЕНЬКОЕ ОБНОВЛЕНИЕ
Архив update применяется ТОЛЬКО поверх полной v32. В нём все изменённые HTML,
новые build-файлы, фото и обновлённые исходники. Старые хешированные build-файлы можно
не удалять — после замены HTML они не подключаются. Замены одного JS недостаточно.

ПРОВЕРКА
1036 локальных ссылок/ресурсов, 22 JSON-LD блока, 17 CSP-хешей загрузчика.
4 изменённые страницы × 4 ширины (320/390/768/1440) — 16 сочетаний.
41 функциональная проверка, включая RU/KZ/EN, увеличение нового фото внутри сайта,
Esc, комнаты/подписи, конец карусели, простую форму и статическую версию без JavaScript.
Это офлайн-стенд Chromium с локальной подстановкой ресурсов. Проверка по реальной сети,
PageSpeed, Safari и физических телефонов не проводилась. Подробности — QA-v33.json.

БУДУЩИЕ ПРАВКИ
npm install → npm run build. Сборщик v32 доработан для всех страниц projects/*.html.
PERF-BUNDLES-v32.json и ASSET-SIZES-v32.json — действующие конфигурации с обновлёнными
данными; историческое имя сохранено для совместимости. При правках текста обновляйте
как JS-источник, так и предрендеренный RU HTML. Шрифтовых файлов в архиве нет.
